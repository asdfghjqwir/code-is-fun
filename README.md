### 💻 Code is Fun!

「プログラミングって、めっちゃ面白い！」を、読むだけでなく実際に触って体験できる1ページの学習用サイトです。 

🔗 公開URL: https://code-is-fun.vercel.app

※「このページを作った人」に登場する人物は架空のフィクションです。 

### 概要

「プログラミングは難しそう」という先入観を説明で消すのではなく、中高生をターゲットに、実際にコードを書き換えてその場で結果が変わる体験を通して面白さを知ってもらうことを目的に制作しました。 

### 主な機能

* **体験型ミッション**: 変数やループなど5つのコードを書き換えるミッション（クリアで紙吹雪）
* **お絵かきコード**: color や shape を書き換えると、右側の図形がリアルタイムに変化
* **あみだくじ言語ナビ**: 作りたいものを選ぶと、おすすめの言語と1か月のロードマップを提示
* **キャリア＆身近な疑問**: 6つのエンジニア職種紹介や、初心者の不安に答えるFAQアコーディオン

### 使用技術

* HTML / CSS / TypeScript / React / Tailwind CSS / Vite / Oxlint / Vercel（公開）

### 工夫した点

* **こだわりのヘッダー・フッター**: ヘッダーはロゴ・ナビ・ボタンを並べた実用的なサービスサイト風にし、フッターはコピーライトだけのシンプルな構成に統一
* **UI/UXとデザインの工夫**: 中高生向けの分かりやすい一言解説の導入と、Google風のポップな配色をCSSの `@theme` で一括管理

#### Claude Codeによる効率的なAI協調開発（バイブコーディング）

AI と会話しながら、設計・実装・確認を進める開発スタイルで作りました。

* **自分で考えたこと**: コンセプト設計、ターゲット選定、Google風への配色変更、あみだくじ等の機能の取捨選択と最終判断
* **AIに任せたこと**: React / Tailwind CSSでのコード実装、追加機能の候補提案、文章案、ビルド確認やGitHubへのPush作業
* **AIのコードの確かめ方**: TypeScript の型チェック（strict）・ビルド・lint で確認しました
* AIが書いたコードをそのまま使うのではなく、方向性や採用機能はすべて自分でコントロールして進めました。

### 今後の改善点

* ミッションの数を増やす（関数の引数、条件の組み合わせ、オブジェクトなど）
* あみだくじの結果を、友だちに送れるシェア用の画像にする
* 診断のように、いくつかの質問に答えて向いている職種がわかる機能
