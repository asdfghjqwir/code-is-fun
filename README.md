# Code is Fun!

「プログラミングって、めっちゃ面白い！」を、読むだけでなく**触って**体験できる 1 ページのサイトです。

🔗 公開URL: https://code-is-fun.vercel.app

## なぜこのアプリを作ったか

プログラミングの面白さを探求したい、というのがきっかけです。
とくに **中高生が読んで理解でき、「自分もやってみたい」と思える** サイトにしたいと考えました。

「プログラミングは難しそう」というイメージを、説明で消すのではなく、実際にコードを書き換えて結果が変わる体験で消すことを目指しています。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| コードを書き換えるミッション | 変数・ループ・条件分岐・リスト・関数の 5 つ。クリアするとバッジがもらえて、紙吹雪が出る |
| コードで絵を描く | `color` や `shape` を書き換えると、右側の図形がその場で変わる |
| あみだくじで言語えらび | 「作りたいもの」を選ぶと、おすすめの言語と最初の 1 か月のロードマップが出る |
| エンジニアの職種紹介 | 6 つの職種と、作っているもの・使う言語・向いている人。「気になる！」で紙吹雪 |
| 身近なプログラムの紹介 | ゲーム・SNS・AI など、毎日使うものもプログラムでできていることを紹介 |
| よくある質問 | 「数学が苦手でも？」など、始める前の不安に答えるアコーディオン |
| このページを作った人 | 3 つの箱にまとめた自己紹介（人物は**架空**のフィクション） |
| そのほか | トップへ戻るボタン、スマホ用ハンバーガーメニュー、スクロールで現れる演出、タイピング演出 |

## 工夫した点

- **あみだくじの結果が必ず筋の通ったものになる**
  横線はランダムですが、「どのスタートから来てもおすすめの言語にたどり着く」ように、ゴールの言語の並びを計算して決めています。
  たとえば「ゲームを作りたい」を選んで Swift が出る、ということが起きません。
- **コードで絵を描く機能を安全に作った**
  入力された文字列をそのまま実行（`eval`）せず、`color` など決まった名前だけを読み取ります。
  書き間違えたときは、何行目がどう違うかを画面に表示します。
- **中高生向けの伝え方**
  専門用語には「変数は名前を入れる箱」のような一言解説を付け、ミッションごとにクリア条件を示しています。
- **Google 風のポップな配色**
  青・赤・黄・緑をセクションごとに使い分け、色は `src/index.css` の `@theme` で一括管理しています。
  白文字でも読めるように、色は少し濃いめにしています。
- **ヘッダー・フッター**
  ヘッダーはロゴ・ナビ・ボタンを並べたサービスサイト風にし、フッターはコピーライトだけにしました。

## 今後の改善点

- ミッションの数を増やす（関数の引数、条件の組み合わせ、オブジェクトなど）
- あみだくじの結果を、友だちに送れるシェア用の画像にする
- 診断のように、いくつかの質問に答えて向いている職種がわかる機能
- スマホの実機での操作確認と、細かい表示崩れの調整
- `App.jsx` が 1 ファイルに大きくなっているので、セクションごとのコンポーネントに分ける
- 使っていない初期ファイル（`src/App.css`、`src/assets/`、`public/icons.svg`）の整理
- 自動テストの追加（あみだくじの結果の計算、お絵かきコードの読み取りなど）
- Oxlint の警告（描画中の `Math.random` など）の解消

## バイブコーディングについて

このアプリは、**Claude Code（AI）と会話しながら作るバイブコーディング** で開発しました。

- **自分で考えたこと**
  サイトのコンセプト（プログラミングの面白さを、中高生にも伝わる形で体験させる）、ターゲット、
  白黒のシックな配色から Google 風のポップな配色への変更、
  「作った人」の架空の紹介ページ、エンジニアの職種紹介、
  「作りたいもの」からおすすめの言語を出すあみだくじ、ヘッダーとフッターの方向性、
  どの追加機能を採用するか（ミッション追加・お絵かき・ロードマップ・FAQ）の取捨選択。
- **AI に任せたこと**
  React / Tailwind CSS でのコードの実装、追加機能の候補の提案、文章案、
  ビルドの確認や GitHub への push などの作業。

AI が書いたコードをそのまま使うのではなく、方向性や採用する機能は自分で判断して進めています。

## 動かし方

Node.js が入っていれば起動できます。

```bash
npm install
npm run dev     # 開発サーバー (http://localhost:5173/)
```

```bash
npm run build   # 本番用ビルド (dist/ に出力)
npm run preview # ビルド結果の確認
npm run lint    # Oxlint でチェック
```

## フォルダ構成

```
code-is-fun/
├── index.html         # エントリーHTML
├── vite.config.js     # React と Tailwind のプラグイン設定
└── src/
    ├── main.jsx       # React の起動
    ├── App.jsx        # ページ全体（セクション・データ・処理）
    └── index.css      # Tailwind の読み込みとテーマ色・アニメーション
```
