# Code is Fun!

「プログラミングって、めっちゃ面白い！」を、中高生にも伝わる形で体験できる 1 ページのサイトです。
読むだけでなく、コードを書き換えたり、あみだくじで言語を選んだりして、「やってみたい」を引き出すことを目指しています。

> 公開URL: (デプロイ後にここへ追記)

## できること

| セクション | 内容 |
| --- | --- |
| ヒーロー | コードがタイピングされる演出つきのトップ |
| 毎日使ってるアレも、実はプログラム | ゲーム・SNS・AI など身近な例 |
| コードを書き換えてみよう | 変数・ループ・条件分岐・リスト・関数の 5 ミッション。クリアでバッジと紙吹雪 |
| コードで絵を描こう | `color` / `shape` / `size` などを書き換えると図形が変わる |
| なぜ、こんなに面白いのか | プログラミングの面白さ 3 つ |
| 楽しさのループ | 書く → 動かす → 壊す → 直す |
| あみだくじで言語えらび | 「作りたいもの」を選ぶと、おすすめ言語と最初の 1 か月のロードマップを表示 |
| エンジニアって、どんな仕事？ | 6 つの職種と、使う言語・向いている人。「気になる！」で紙吹雪 |
| 次は、君の番だ | はじめかたの 3 ステップ |
| よくある質問 | 「数学が苦手でも？」などの不安に答える |
| このページを作った人 | 架空のプロフィール（フィクション） |

そのほか、トップへ戻るボタン、スマホ用ハンバーガーメニュー、スクロールで現れるアニメーションがあります。

## 使っている技術

- [React](https://react.dev/) 19
- [Vite](https://vite.dev/)
- [Tailwind CSS](https://tailwindcss.com/) v4（`@tailwindcss/vite`）
- Oxlint

## 動かし方

Node.js が入っていれば、次の手順で起動できます。

```bash
npm install
npm run dev     # 開発サーバー (http://localhost:5173/)
```

```bash
npm run build   # 本番用ビルド (dist/ に出力)
npm run preview # ビルド結果の確認
npm run lint    # Oxlint でチェック
```

## フォルダ構成

```
code-is-fun/
├── index.html         # エントリーHTML
├── vite.config.js     # React と Tailwind のプラグイン設定
└── src/
    ├── main.jsx       # React の起動
    ├── App.jsx        # ページ全体（セクション・データ・処理）
    └── index.css      # Tailwind の読み込みとテーマ色・アニメーション
```

## 工夫したところ

- **あみだくじ**: 横線はランダムですが、ゴールの言語は「どのスタートから来てもおすすめの言語にたどり着く」ように並べています。
- **コードで絵を描く**: 入力されたコードをそのまま実行せず、`color` などの決まった名前だけを読み取る小さな仕組みにしています。
- **配色**: Google 風の青・赤・黄・緑を、セクションごとに使い分けています。色は `src/index.css` の `@theme` で一括管理しています。
