### 💻 Code is Fun!

「プログラミングって、めっちゃ面白い！」を、読むだけでなく実際に触って体験できる1ページの学習用サイトです。 

🔗 公開URL: https://code-is-fun.vercel.app 

※「このページを作った人」に登場する人物は架空のフィクションです。 

### 概要

「プログラミングは難しそう」という先入観を説明で消すのではなく、中高生をターゲットに、実際にコードを書き換えてその場で結果が変わる体験を通して面白さを知ってもらうことを目的に制作しました。 

### 主な機能

* **体験型ミッション**: 変数やループなど5つのコードを書き換えるミッション（クリアで紙吹雪）
* **お絵かきコード**: color や shape を書き換えると、右側の図形がリアルタイムに変化
* **あみだくじ言語ナビ**: 作りたいものを選ぶと、おすすめの言語と1か月のロードマップを提示
* **キャリア＆身近な疑問**: 6つのエンジニア職種紹介や、初心者の不安に答えるFAQアコーディオン

### 使用技術

HTML/CSS /React /Tailwind CSS /vite　/Oxlint /Vercel（公開） 

### 工夫した点

* **こだわりのヘッダー・フッター**: ヘッダーはロゴ・ナビ・ボタンを並べた実用的なサービスサイト風にし、フッターはコピーライトだけのシンプルな構成に統一
* **UI/UXとデザインの工夫**: 中高生向けの分かりやすい一言解説の導入と、Google風のポップな配色をCSSの @theme で一括管理
* **Claude Codeによる効率的なAI協調開発（バイブコーディング）**: 

  * **自分が主導したこと**: コンセプト設計、Google風への配色変更、あみだくじ等の機能選定と最終判断
  * **AIに任せたこと**: React/Tailwindによるコード実装、追加機能の候補出し、ビルドやGitHubへのPush作業
  * AIのコードを丸呑みせず、方向性や採用機能はすべて自分でコントロールして進めました。

* [ ] あみだくじの結果を、友だちに送れるシェア用の画像にする

## バイブコーディングについて

このアプリは、**Claude Code（AI）と会話しながら作るバイブコーディング** で開発しました。

- **自分で考えたこと**
  サイトのコンセプト（プログラミングの面白さを、中高生にも伝わる形で体験させる）、ターゲット、
  白黒のシックな配色から Google 風のポップな配色への変更、
  「作った人」の架空の紹介ページ、エンジニアの職種紹介、
  「作りたいもの」からおすすめの言語を出すあみだくじ、ヘッダーとフッターの方向性、
  どの追加機能を採用するか（ミッション追加・お絵かき・ロードマップ・FAQ）の取捨選択。
- **AI に任せたこと**
  React / Tailwind CSS でのコードの実装、追加機能の候補の提案、文章案、
  ビルドの確認や GitHub への push などの作業。

AI が書いたコードをそのまま使うのではなく、方向性や採用する機能は自分で判断して進めています。
